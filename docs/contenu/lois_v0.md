# Lois V0

Format : nom court (≤ 24 car.), description (≤ 3 lignes de 38 col.),
titres du journal. Les effets sont définis par la simulation ;
la ligne « Effets suggérés » est indicative.

## LOI_SMIC
Nom : Hausse du SMIC
Description :
  Revalorise le SMIC de 5 %. Salaires
  suivent, les marges patronales
  protestent. L'UPE parle de « drame ».
Journal si adoptée : Le SMIC grimpe, les caisses sonnent
Journal si rejetée : SMIC rejeté, les prix eux montent
Effets suggérés : popularité populaires en hausse, cadres en baisse, chômage légèrement en hausse, jeunes en hausse.

## LOI_IS
Nom : Baisse de l'IS
Description :
  Réduit l'impôt sur les sociétés pour
  « libérer l'investissement ». Les
  recettes de l'État s'évaporent.
Journal si adoptée : IS en baisse, on trinque en haut
Journal si rejetée : IS : texte enterré, l'UPE fulmine
Effets suggérés : économie et cadres en hausse, dette en hausse, classes populaires en baisse, jeunes en baisse.

## LOI_RENOV
Nom : Rénovation thermique
Description :
  Finance l'isolation de millions de
  logements. Les passoires thermiques
  chauffent moins, les chantiers plus.
Journal si adoptée : Plan rénovation : les murs s'isolent
Journal si rejetée : Rénovation : les passoires restent
Effets suggérés : écologie et emploi en hausse à terme, dette en hausse, effet différé, retraités en hausse, jeunes en hausse.

## LOI_POLICE
Nom : Recrutement de policiers
Description :
  Recrute 10 000 policiers sur le
  quinquennat. Plus de bleu dans les
  rues, plus de lignes dans le budget.
Journal si adoptée : 10 000 policiers dans les rues
Journal si rejetée : Police : recrutement bloqué
Effets suggérés : sécurité en hausse, classes moyennes en hausse, dette en hausse, tension en baisse, retraités en hausse, jeunes en baisse.

## LOI_CIR
Nom : Crédit d'impôt recherche
Description :
  Renforce le crédit d'impôt recherche.
  Les labos respirent, les cabinets de
  conseil en optimisation aussi.
Journal si adoptée : Recherche : crédit pour les labos
Journal si rejetée : CIR rejeté, labos sur la paillasse
Effets suggérés : technologie et économie en hausse à terme, dette en hausse, cadres en hausse, jeunes en hausse.
